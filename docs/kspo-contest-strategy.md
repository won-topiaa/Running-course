# KSPO 공공데이터 활용 경진대회 — 런코스 전략

> 대회: 서울올림픽기념국민체육진흥공단 공공데이터 활용 경진대회
> 접수 마감: 2026-10-02
> 앱: 런코스 (Running-course PWA)

---

## 1. 핵심 아이디어

**체력 진단 → 개인 맞춤 러닝 코스 처방**

국민체력100 측정결과 데이터에서 연령·성별 체력 분포를 추출하고,
사용자의 체력 수준을 이 분포 위에 놓아 백분위를 산출한 뒤,
그에 맞는 거리·경사·경로 스타일을 처방하여 코스를 생성한다.

단순한 "체력 좋으면 먼 거리" 식 분류가 아니라,
101개 분위 기반 연속 보간으로 사용자 체력에 비례하는 매끄러운 처방을 제공한다.

### 2.1 데이터 수집 API

```
엔드포인트: https://www.data.go.kr/data/15108938/openapi.do
인증: API Key (data.go.kr)
호출 방식: REST GET → JSON
수집 스크립트: scripts/fetch-fitness-norm.mjs
```

### 2.2 수집 방법론

- **샘플링**: 연도별 슬라이스 샘플링 (2022 Q1~Q4, 2023 Q1~Q4, 2024 Q1~Q2)
  - 페이지 순차 수집 시 2023 Q1 편향 발생 → 연도별 균등 샘플링으로 해결
- **코호트**: 12개 (남/여 × 20대/30대/40대/50대/60대/70+)
- **코호트당 표본**: 4,000건
- **총 표본**: 48,000건 (12 × 4,000)
- **수집 기간**: 코호트별 17~26개월 span

### 2.3 데이터 정제

| 정제 항목 | 방법 | 근거 |
|---------|------|------|
| VO₂max 측정방식 분리 | 스텝+트레드밀만 채택, 왕복 달리기(f030) 제외 | 왕복 달리기 중앙값이 2~3 낮음 (6개 코호트 검증) |
| 악력 집계 | max(좌, 우) 사용 | 상대악력 = max(좌,우)/체중×100 역산으로 증명 (1000/1000 일치) |
| 미측정값 | 0값 분리 (측정 안 함 vs 실제 0) | 0값 72,015건은 미측정으로 확인, 실제 이상치 154건과 분리 |
| BMI | 체중/(신장m)² 역산 검증 | 2999/3000건 일치 (1건은 반올림 차이) |
| 분위 압축 | 101개 분위 (0, 1, 2, ..., 100) | 4,000건 → 101개로 압축, 보간 정밀도 확보 |

## 3. 구현 현황

### 3.1 완료 (claude/fitness-prescription 브랜치)

#### A. 체력 평가 시스템
- **국민체력100 데이터 연동** (`src/lib/kspoFitness.ts`)
  - 12개 코호트별 분포 데이터 탑재 (`src/data/fitnessNorm.json`, 69KB)
  - 7개 측정 항목 지원: VO₂max, 악력, BMI, 유연성, 제자리멀리뛰기, 10m 왕복, 반응시간
  - 측정방식 분리: VO₂max는 스텝+트레드밀만 (왕복달리기 제외)
  - 악력 max(좌,우) 집계
- **VO₂max 추정** (`src/lib/vo2max.ts`)
  - 일반 달리기: Daniels & Gilbert VDOT 공식
  - Cooper 12분 검사: (거리m - 504.9) / 44.73
  - 두 방식 자동 판별 (isCooperTest 플래그)

#### B. 코스 처방 엔진
- **연속 보간 처방** (`src/lib/fitness.ts`)
  - 앵커 포인트 기반 연속 보간 (이전: 3단계 절벽식 분류)
  - 처방 항목: 거리(km), 최대 경사(%), 인터벌 비율(%)
  - 0.2km 이하 점프 보장 (연속성 검증 통과)
  - coverage 필드: 평가된 항목의 가중치 합산 (불충분한 데이터로 처방 시 표시)
  - VO₂max 항목 필수 (악력만으로 처방하지 않음)

#### C. Cooper 12분 검사 모드
- **검사 UI** (`src/components/RecordScreen.tsx`)
  - GPS 첫 수신 시 타이머 자동 시작 (벽시계 기준)
  - 일시정지 불가 (벽시계 검사이므로)
  - 음성 큐: 10분/5분/3분/1분/10초 남음 안내
  - 결과 화면: VO₂max, 백분위, 간극 경고
- **검사 진입점** (`src/components/FitnessSection.tsx`)
  - 추정치 있을 때: "12분 검사로 정확하게 재기"
  - 추정치 없을 때: "12분 검사 시작" 카드
  - 70+/청소년: 데이터 부재 시 정직한 안내

## 7. 알려진 제한사항 (보고서에 정직하게 기재)

| 항목 | 제한 | 대응 |
|------|------|------|
| age_degree 모호성 | API 필드가 10세 단위인지 개별 나이인지 문서에 명시 안 됨 | 10세 단위로 가정, 실제 분포와 교차 검증 |
| 측정방식 차이 | 스텝/트레드밀 간에도 소폭 차이 존재 | 현재는 합산, 향후 방식별 분리 가능 |
| 비교 대상 | 일반 국민 대비 백분위 (러너 대비 아님) | 사용자에게 "일반인 기준" 명시 |
| 70+/청소년 | VO₂max 데이터 부족 (측정건수 소) | UI에서 정직하게 안내, 처방 제한 |
| 지역 한정 | 현재 서울 코스만 | 라우팅 엔진은 좌표 기반이라 전국 확장 가능 |
| Cooper 검사 정확도 | GPS 정확도에 의존 (±5~15m) | 검사 결과에 간극 경고 표시 |
