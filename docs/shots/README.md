# 보고서용 스크린샷

`npm run shots` 로 다시 찍는다 (`npm run build` 가 먼저 돌아야 한다).

빌드된 `dist` 를 로컬 서버에 올리고 실제 크로미움으로 열어 찍는다.
iPhone 14 Pro 크기(390×844), 배율 2배, 한국어·서울 시간대.
출발점은 잠실 근처 좌표(37.5285, 127.0276)를 물려 둔다.

| 파일 | 화면 | 담긴 것 |
|------|------|--------|
| `A.png` | 마이 → 내 체력 | 입력값, 또래 백분위, 코스 처방, 데이터 출처 표기 |
| `B.png` | 12분 검사 | 검사 안내와 중단 조건, START |
| `C.png` | 만들기 결과 | 실제 보행 경로, 경사 색상, 후보 비교 카드 |
| `D.png` | 근처 공공체육시설 | 데이터셋 15107764 실데이터 (자치구·유형·거리) |
| `E.png` | 예상 혼잡도 | 혼잡도 등급과 한적한 시간대 추천 |
| `F.png` | 러닝 기록 | 지도 위 주행 경로, 거리·시간·페이스 |

## 이 환경에서만 필요한 처리 두 가지

**외부 요청을 Node 로 중계한다.**
바깥 통신이 로컬 프록시를 거치고 TLS 가 그 앞에서 다시 끝나는데, Playwright 가
띄우는 크로미움은 그 CA 를 읽지 않아 지도 타일·보행 경로·고도 조회가 전부
끊긴다. 인증서 검증을 끄는 대신(그건 하면 안 된다) 요청을 Node 로 넘겨
정상적으로 검증된 응답을 브라우저에 돌려준다. 일반 PC 에서 돌릴 때는
없어도 되는 우회다.

**F 는 지도와 기록 수치까지만 자른다.**
그 아래에 붙는 '음성 안내가 이 기기에서 재생되지 않아요' 는 헤드리스
크로미움에 음성 합성 엔진이 없어서 뜨는 것이지, 실제 휴대폰에서 나오는
화면이 아니다. 그대로 실으면 없는 고장을 보여주게 된다.

## 다시 찍을 때 걸리기 쉬운 곳

- **B 는 저장소를 비우고 들어가야 한다.** A 에서 심폐지구력을 넣으면 그 값이
  남아 '12분 검사 시작' 카드가 사라진다 (이미 아는 사람에게는 안 권하는 화면).
- **`dismissHints` 는 exact 로 찾는다.** 부분 일치로 두면 '시작하기' 가 마이
  페이지의 '첫 러닝 시작하기' 를 눌러 화면을 통째로 벗어난다.
- **12분 검사 화면에서는 힌트 정리를 부르지 않는다.** 그 화면의 '닫기' 를 눌러
  방금 들어온 화면을 되돌아 나온다.
- **기록 화면은 오버레이다.** `body.innerText` 앞부분에는 뒤에 깔린 화면이
  잡히므로, 열렸는지 보려면 화면 고유 문구로 찾아야 한다.
