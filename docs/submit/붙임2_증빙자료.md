## 4. 기대효과 (파급효과) — 정량·정성

### 4-1. 정량적 효과

| 지표 | 수치 | 확인 방법 |
|------|------|----------|
| 활용 공공데이터 | 공단 3건 + 타 공공데이터 2종(지하철) = **5종** | §5 데이터 활용 부분 |
| 활용 데이터 규모 | 체력측정 47,976건 표본 + 공공체육시설 1,284행(고유 1,272개소) + 측정건수 8,161행 + 지하철 12개 노선 403역 | 각 데이터 파일 |
| 체력 분포 해상도 | 12개 코호트 × 101개 분위 | `src/data/fitnessNorm.json` |
| 처방 연속성 | 인접 분위 간 처방 차이 **≤ 0.2km** | 자동 검증(`fitness-check`)이 강제 |
| 접근 비용 | **0원** — 설치·회원가입·API 키 없이 사용 | PWA, 무료 외부 서비스만 사용 |
| 품질 보증 | 15개 스크립트 **15,885개 자동 검증** 통과 | `npm run check`(15,838) + `check:scenario`(25) + `check:smoke`(21) |

### 4-2. 정성적 효과

1. **데이터의 개인 환원** — 집계 통계로만 존재하던 국민체력100 데이터가 개인에게 "당신은 또래 중 몇 번째"라는 구체적 피드백으로 돌아온다.
2. **제도 참여 유도** — 정확한 처방을 받으려면 실제 측정이 필요하다는 구조 자체가 국민체력100 측정 참여 동기가 되고, 서울 22개 인증센터 현황으로 "어디서 측정받을지"까지 연결한다.
3. **공공데이터 결합 가치** — 체력(어떤 코스) + 시설(어디서 출발) + 혼잡도(언제) + 지하철(어떻게 돌아올지)을 묶어 단일 데이터셋으로는 불가능한 답을 만든다.
4. **공공체육시설 이용 촉진** — 코스 주변 시설을 자동 안내해 러너가 몰랐던 인근 시설을 알린다.

> 상세는 [붙임1] 활용사례 보고서 §5 참조.
>
> **■ 첨부 ⑥** — (선택) 검증 실행 결과 화면. `npm run check` 는 데이터·로직 검증 15,838개,
> `npm run check:scenario` 는 화면 시나리오 26개, `npm run check:smoke` 는 실제 브라우저 구동 21개를
> 각각 돌린다. 셋을 합쳐 15,885개이며, 세 화면을 나란히 붙이면 품질 근거로 유용하다.

## 5. 국민체육진흥공단 데이터가 활용된 부분

### 5-1. 활용 데이터 3건 (공단) + 융합 2종

| 데이터셋 | 이름 | 출처(데이터포털) | 데이터 파일 | 활용 코드 |
|---------|------|-----------------|-----------|----------|
| **15108938** | 국민체력100 체력측정결과 정보 | data.go.kr/data/15108938 | `src/data/fitnessNorm.json` | `src/lib/kspoFitness.ts`, `fitness.ts` |
| **15107764** | 공공체육시설 상세 정보 | data.go.kr/data/15107764 | `src/data/facilities.json` | `src/lib/facilities.ts`, `components/NearbyFacilities.tsx` |
| **15114286** | 국민체력100 측정건수 | data.go.kr/data/15114286 | `src/data/testCounts.json` | `src/lib/testCounts.ts`, `components/FitnessInsight.tsx` |
| (융합) 지하철 | 국가철도공단·서울교통공사 역위치 | 공공데이터포털 | `src/data/subway.json` | `src/lib/subway.ts`, `components/StationPicker.tsx` |

각 데이터 파일에는 **출처(source) 필드**가 박혀 있어 어느 공공데이터에서 왔는지 파일 자체로 확인된다.

```
fitnessNorm.json  → "국민체력100 체력인증센터 측정결과 정보(공공데이터포털 15108938)"
facilities.json   → "공공체육시설 상세 정보 (15107764)"
testCounts.json   → "체력인증센터 측정건수 (15114286)"
subway.json       → "국가철도공단 역위치 · 서울교통공사 1~8호선 역사 좌표 — 공공데이터포털"
```

### 5-2. 데이터가 서비스의 어디에 쓰이는가

- **15108938 체력측정결과** — 서비스의 **핵심**. 47,976건에서 연령·성별 분포(12코호트 × 101분위)를 뽑아 사용자 체력의 백분위를 산출하고, 그에 비례하는 거리·경사·인터벌을 **연속으로 처방**한다. 단순 조회가 아니라 **의사결정 엔진의 입력**이다.
- **15107764 공공체육시설** — 코스 경로 주변 500m 이내 시설을 자동 안내(만들기·추천코스·경로시트 3개 화면).
- **15114286 측정건수** — 국민체력100 참여 현황(누적 273만 건, 연도별 추세, 서울 인증센터)을 시각화.
- **(융합) 지하철** — '역에서 역으로' 코스의 출발·도착·중간하차역. 공고가 허용한 타 공공데이터 융합 사례.

> 데이터 수집·정제의 구체적 과정(측정방식 분리, 악력 기준 역산, 두 지하철 데이터 교차검증 등)은 [붙임1] 보고서 §4·§6-4 참조.
>
> **■ 첨부 ⑦** — (선택) 앱에서 데이터가 실제로 표시되는 화면. 보고서 스크린샷(그림 1 체력 백분위, 그림 6 공공체육시설)으로 갈음 가능.
