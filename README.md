# 🏃 런코스 — 취향으로 찾는 나만의 서울 러닝 코스

매번 똑같은 코스가 지겹지만 새 코스를 짜기는 번거로운 러너를 위해,
**내 취향과 조건을 입력하면 서울의 러닝 코스를 점수화해 추천**해주는 웹앱입니다.

사용자가 6가지 요소의 중요도와 취향을 정하면, 각 코스를 가중치 기반으로
채점(0~100%)해 순위와 **추천 이유**까지 함께 보여줍니다.

## 추천에 반영하는 6가지 요소

| 요소 | 설명 |
| --- | --- |
| ⛰️ **경사도** | 평지 / 완만한 언덕 / 언덕 많음. 원하는 경사 난이도와의 일치도 |
| 💚 **코스 취향** | 시티런 · 끊김 없는 · 그린런 · 워터프론트 · 트레일 · 트랙 (복수 선택) |
| 🛡️ **안전·조명** | 가로등 · CCTV · 야간 러닝 적합 · 신호등/차량 없는 정도 |
| 🚰 **편의시설** | 식수대 · 화장실 · 편의점 · 주차 · 지하철 접근성 |
| 🌆 **경관·환경** | 녹지 · 야경 · 그늘 등 풍경 만족도 |
| 📏 **거리** | 목표 거리와의 근접도 (순환·왕복 코스는 바퀴 수/반환 조절 반영) |

> 코스 취향 항목은 최근 러너 커뮤니티/공개 자료 리서치를 바탕으로 정리했습니다.
> 특히 **"끊김 없는 코스(신호등·횡단보도·차량 없음)"** 와 자연 속을 달리는
> **"그린런/워터프론트"** 선호가 두드러졌고, 한강처럼 **가로등·CCTV가 잘 갖춰진
> 야간 안전 코스**와 **식수대·화장실 등 편의시설**이 반복적으로 강조되었습니다.

## 주요 기능

- **취향 가중치 매칭 엔진** — 6요소 중요도 슬라이더(0~5) + 취향 태그 + 목표 거리 +
  경사 선호 + 야간 러닝 여부를 조합해 코스별 매칭 점수를 계산
- **실제 지도 표시** — Leaflet + OpenStreetMap으로 서울 실제 지형 위에 코스 경로를
  그리고, 상위 추천은 강조 색으로 구분
- **추천 이유·주의사항 자동 생성** — "평지라 일정한 페이스에 좋아요", "한 바퀴
  2.5km 순환이라 2바퀴면 목표에 맞출 수 있어요", "야간엔 조명이 약해요" 같은
  자연어 설명
- **코스 상세** — 고도 프로파일 차트, 요소별 점수 바, 편의시설 아이콘, 노면·경관
  태그, 러너 팁
- **설정 자동 저장** — 선호값을 localStorage에 저장해 다음 방문 시 복원
- **라이트/다크 테마 · 반응형** — 데스크톱 3열, 모바일 세로 스택

## 수록 코스 (서울 14곳)

반포·여의도·뚝섬·잠실 한강공원, 남산 순환로, 올림픽공원, 서울숲, 청계천,
양재천, 석촌호수, 경의선숲길(연트럴파크), 월드컵공원 하늘공원, 북서울꿈의숲, 탄천

## 기술 스택

- **React 18 + TypeScript + Vite**
- **Leaflet / react-leaflet** (지도, OpenStreetMap 타일 — API 키 불필요)
- 차트·UI는 외부 의존성 없이 순수 SVG/CSS로 구현

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입체크 + 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
```

## 프로젝트 구조

```
src/
├─ data/courses.ts       # 서울 코스 큐레이션 데이터 + 고도 프로파일 합성
├─ lib/
│  ├─ types.ts           # 도메인 타입 (코스·선호·추천 결과)
│  └─ scoring.ts         # 취향 가중치 추천 엔진 + 자연어 설명 생성
├─ components/
│  ├─ PreferencePanel.tsx # 선호 입력 UI
│  ├─ CourseMap.tsx       # Leaflet 지도 + 코스 경로
│  ├─ CourseCard.tsx      # 랭킹 카드 + 상세
│  └─ ElevationChart.tsx  # 고도 프로파일 SVG 차트
└─ App.tsx               # 상태 관리 · 레이아웃
```

## 데이터에 관한 참고

현재 코스의 **GPS 경로 좌표는 실제 권역을 따라 단순화한 값**이며(지도에 코스의
위치·형태를 보여주기 위한 용도), 6요소 속성값은 러너 커뮤니티/공개 정보를 바탕으로
한 큐레이션입니다.

## 향후 확장 방향

- **실데이터 연동** — 지자체 DEM(수치표고모델)로 실제 경사, 공공데이터 POI로
  식수대·화장실·조명 위치, 야간 조도/CCTV 데이터로 안전 점수 산출
- **지도 제공자 교체** — Leaflet 계층만 카카오/네이버 지도 SDK로 교체 가능하도록 구성
  (현재는 키 없이 동작하는 OpenStreetMap 사용)
- **경로 자동 생성** — 출발지·목표 거리·취향을 받아 최적 경로를 실시간 생성
- **개인화** — 러닝 기록/스트라바 연동으로 취향 자동 학습
